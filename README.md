# BIMAssistant
Repositório destinado ao projeto escopo de plug-in Revit voltado para auxílio, otimizações e acessos à bibliotecas com aplicação de IA.

Trata-se de um estudo de criação de plu-in usando a linguagem C# que ajude e facilite desenvolvimento de projetos e famílias.
*OBS*: Esse projeto é um escopo que contém conteúdos simplórios para demonstrar as possibilidades de uso de um plug-in com utilização de inteligência artificial para gerenciamento de demandas do usuário.
